## 1. Discovery Phase

### 1.1 Goals (North Star)

**Primary Goal**: Prove the CLI concept by enabling developers to scaffold a working Lua plugin in under 5 minutes.

**Specific Goals**:
- ✅ Install SDK CLI globally
- ✅ Scaffold a plugin project with `blockcore new`
- ✅ Generated project has valid manifest
- ✅ Project structure follows conventions
- ✅ Includes basic example code

### 1.2 Success Criteria

**Must Have (MVP)**:
- [ ] CLI tool installable via `dotnet tool install -g BlockCore.SDK`
- [ ] `blockcore new plugin <name>` command works
- [ ] Generates project with `manifest.json`, `main.lua`, `README.md`
- [ ] Manifest validates against basic schema
- [ ] Template includes example "/hello" command
- [ ] Works on Windows, Linux, macOS

**Should Have**:
- [ ] `--lang lua` flag (for future JS support)
- [ ] `--output` flag to specify directory
- [ ] Color-coded console output (success/error)
- [ ] Version command (`blockcore --version`)

**Nice to Have**:
- [ ] `blockcore help` with examples
- [ ] Auto-detect author name from git config
- [ ] Generate `.gitignore` for plugin projects

### 1.3 Non-Goals (Out of Scope for v0.1)

❌ Validation command (comes in v0.2)  
❌ Pack/install commands  
❌ Multiple templates (only plugin-lua)  
❌ Schema validation  
❌ Hot-reload / watch mode  
❌ Signing or packaging  

### 1.4 Stakeholders

| Role | Responsibility |
|------|---------------|
| **SDK Developer** | Implement CLI tool, templates, schemas |
| **Plugin Developer** | Test scaffolding, provide feedback |
| **BlockCore Team** | Define plugin API contracts |

## 3. Project Definition

### 3.1 CLI Commands (v0.1)

#### `blockcore new plugin <name>`

**Purpose**: Scaffold a new plugin project

**Syntax**:
```bash
blockcore new plugin <NAME> [OPTIONS]
```

**Options**:
- `--lang <lua|js>` - Scripting language (default: lua, js not implemented in v0.1)
- `--output <PATH>` - Output directory (default: `./<NAME>`)
- `--author <NAME>` - Plugin author (default: git config or "Unknown")

**Example**:
```bash
blockcore new plugin HomeTP --lang lua --author "YourName"
```

**Output**:
```
Creating plugin 'HomeTP'...
✓ Created directory: HomeTP/
✓ Generated manifest.json
✓ Generated main.lua
✓ Generated README.md

Plugin 'HomeTP' created successfully!

Next steps:
  1. cd HomeTP
  2. Edit main.lua to add your logic
  3. Validate: blockcore validate . (coming in v0.2)

Learn more: https://docs.blockcore.dev/sdk/plugins
```

#### `blockcore --version`

**Purpose**: Display CLI version

**Output**:
```
BlockCore SDK v0.1.0
.NET Tool for creating BlockCore extensions

Engine compatibility: BlockCore v0.1+
```

#### `blockcore --help`

**Purpose**: Show available commands and options

### 3.2 Template Structure (plugin-lua)

**Generated files**:

```
HomeTP/
  ├─ manifest.json
  ├─ main.lua
  ├─ README.md
  └─ .gitignore (optional)
```

**manifest.json**:
```json
{
  "id": "{{ author }}:{{ name_lower }}",
  "name": "{{ name }}",
  "version": "0.1.0",
  "type": "plugin",
  "engine": "^0.5",
  "description": "A BlockCore plugin created with BlockCore SDK",
  "author": "{{ author }}",
  "license": "MIT",
  "entry": "main.lua",
  "side": "server",
  "permissions": [
    "commands.register",
    "chat.send"
  ],
  "capabilities": [
    "chat"
  ]
}
```

**main.lua**:
```lua
-- {{ name }} Plugin
-- Author: {{ author }}
-- Created with BlockCore SDK v{{ sdk_version }}

function onLoad(ctx)
    print("[{{ name }}] Loading plugin...")
    
    -- Register example command
    ctx:registerCommand("hello", {}, function(c)
        c:reply("Hello from {{ name }}!")
    end, { permission = "player" })
    
    print("[{{ name }}] Plugin loaded successfully!")
end

function onEnable(ctx)
    print("[{{ name }}] Plugin enabled")
end

function onDisable(ctx)
    print("[{{ name }}] Plugin disabled")
end
```

**README.md**:
```markdown
# {{ name }}

{{ description }}

## Installation

1. Copy this folder to your game's `plugins/` directory
2. Restart the game or reload plugins
3. Test with `/hello` command

## Commands

- `/hello` - Test command that responds with a greeting

## Development

Edit `main.lua` to add your custom logic.

## License

{{ license }}
```

## 4. Preliminary Design

### 4.1 CLI Architecture

```
┌─────────────────────────────────────────┐
│   BlockCore.SDK.CLI (Console App)       │
│                                         │
│  ┌──────────────────────────────────┐  │
│  │  System.CommandLine              │  │

│  └──────────────┬───────────────────┘  │
│                 │                       │
│  ┌──────────────┴───────────────────┐  │
│  │  NewCommand                      │  │
│  │  - Load template                 │  │
│  │  - Substitute variables          │  │
│  │  - Write files                   │  │
│  └──────────────┬───────────────────┘  │
│                 │                       │
│  ┌──────────────┴───────────────────┐  │
│  │  TemplateEngine (Scriban)        │  │
│  │  - Render manifest               │  │
│  │  - Render main.lua               │  │
│  │  - Render README                 │  │
│  └──────────────────────────────────┘  │
└─────────────────────────────────────────┘
```

### 4.2 Template Variable Substitution

**Input**:
```bash
blockcore new plugin HomeTP --author "Alice"
```

**Variables**:
```json
{
  "name": "HomeTP",
  "name_lower": "hometp",
  "author": "Alice",
  "description": "A BlockCore plugin created with BlockCore SDK",
  "license": "MIT",
  "sdk_version": "0.1.0",
  "date": "2025-10-18"
}
```

**Output**: Files with variables replaced

### 4.3 Code Example (NewCommand)

```csharp
public class NewCommand
{
    public async Task<int> ExecuteAsync(
        string type,      // "plugin"
        string name,      // "HomeTP"
        string? lang,     // "lua"
        string? output,   // "./HomeTP"
        string? author)   // "Alice"
    {
        // Validate inputs
        if (string.IsNullOrWhiteSpace(name))
        {
            ConsoleHelper.Error("Plugin name is required");
            return 1;
        }
        
        // Determine output directory
        var outputDir = output ?? Path.Combine(Directory.GetCurrentDirectory(), name);
        
        // Check if directory exists
        if (Directory.Exists(outputDir))
        {
            ConsoleHelper.Error($"Directory '{outputDir}' already exists");
            return 1;
        }
        
        // Prepare template variables
        var variables = new Dictionary<string, object>
        {
            ["name"] = name,
            ["name_lower"] = name.ToLowerInvariant(),
            ["author"] = author ?? GetGitAuthor() ?? "Unknown",
            ["description"] = $"A BlockCore plugin created with BlockCore SDK",
            ["license"] = "MIT",
            ["sdk_version"] = "0.1.0",
            ["date"] = DateTime.UtcNow.ToString("yyyy-MM-dd")
        };
        
        // Load template
        var templatePath = GetTemplatePath("plugin-lua");
        
        // Render files
        ConsoleHelper.Info($"Creating plugin '{name}'...");
        Directory.CreateDirectory(outputDir);
        
        await RenderTemplate(templatePath, "manifest.json", outputDir, variables);
        await RenderTemplate(templatePath, "main.lua", outputDir, variables);
        await RenderTemplate(templatePath, "README.md", outputDir, variables);
        
        ConsoleHelper.Success($"Plugin '{name}' created successfully!");
        ConsoleHelper.Info($"\nNext steps:");
        ConsoleHelper.Info($"  1. cd {name}");
        ConsoleHelper.Info($"  2. Edit main.lua to add your logic");
        ConsoleHelper.Info($"  3. Validate: blockcore validate . (coming in v0.2)");
        
        return 0;
    }
}
```
