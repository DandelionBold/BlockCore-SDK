## 🎨 Preliminary Design

### SDK Architecture
```
BlockCore-SDK/
├─ CLI/             # Command-line interface
│  ├─ Commands     # CLI commands
│  ├─ Options       # Command options
│  └─ Program       # Main entry point
├─ Templates/       # Project templates
│  ├─ Plugin        # Plugin template
│  ├─ Resource      # Resource pack template
│  └─ Data          # Data pack template
├─ Validation/      # Schema validation
│  ├─ Schemas       # JSON schemas
│  ├─ Validators    # Validation logic
│  └─ Errors        # Error reporting
├─ Packaging/       # Package creation
│  ├─ Builder       # Package builder
│  ├─ Manifest      # Manifest generation
│  └─ Compression   # ZIP compression
└─ Installation/    # Local installation
   ├─ Installer     # Installation logic
   ├─ Manager       # Package management
   └─ Registry      # Local registry
```

### Key Classes
- **CLIProgram**: Main CLI application
- **ScaffoldCommand**: Project scaffolding
- **ValidateCommand**: Project validation
- **PackCommand**: Package creation
- **InstallCommand**: Local installation
- **TemplateEngine**: Template processing

### CLI Structure
```
blockcore
├─ new <type> <name>     # Scaffold new project
├─ validate <path>       # Validate project
├─ pack <path>           # Create package
├─ install <package>     # Install package
└─ --help                # Show help
```
